# Project scope

This repository packages the five-module Track 1 RCA runtime, Docker entry point, tests, offline evaluation harness, measured repair experiments, activity context and optional demo.

The published runtime is repairs 1,2,3,4,6. It excludes agentstest, Track 2 implementation, raw datasets, API credentials and full local diagnostic caches. See [architecture](docs/ARCHITECTURE.md), [report](REPORT.md), and [event](docs/HACKATHON.md).

It is an evidence-backed research prototype, not a proven production incident responder. The final runtime has a single measured 20-case seven-task development run, not a hidden-test score or repeated full-70 validation.
